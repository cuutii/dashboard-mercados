# Dashboard de Mercados — Acciones y Cripto en tiempo real

Dashboard web estático (HTML/CSS/JS puro, sin build) para ver precios de acciones y criptomonedas en tiempo real.

## Live (GitHub Pages)
https://cuutii.github.io/dashboard-mercados/

## Características
- Criptomonedas: top 10/25/50 por capitalización (CoinGecko), búsqueda, gráfico de 7 días.
- Acciones: tickers populares vía Yahoo Finance (proxy público), agregar ticker manual.
- Watchlist personal (localStorage).
- Auto-actualización cada 60 s.
- Responsive (móvil 375 px), tema oscuro.

## Stack
- HTML5, CSS3, JavaScript (ES6)
- Chart.js (CDN)
- APIs: CoinGecko (cripto), Yahoo Finance vía allorigins (acciones)

## Uso
Abrir `index.html` con doble clic, o visitar el enlace live. No requiere build ni servidor.

## Aviso
Solo con fines informativos. No es asesoramiento financiero.
